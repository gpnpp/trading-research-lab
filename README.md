# trading-research-lab

Исследовательская лаборатория для проверки торговых стратегий на реальных данных: от «красивых идей» до честного вывода.
Весь код на Python (стандартная библиотека, без обязательных зависимостей). Это **исследование, а не торговый совет**.

> **English TL;DR.** A reproducible, no-hype lab that backtests popular retail strategies (TJR/ICT sweep → BOS → OB retest, volume breakouts,
> mean-reversion, EMA trend) on crypto, indices, FX and gold with realistic costs, funding and out-of-sample splits.
> Almost everything lost money after costs. The only survivor is a slow, vol-targeted 4h EMA-trend portfolio (~Sharpe 0.9). Includes a paper-trading
> Solana meme-coin scanner and a small dashboard.

## Главные выводы (все цифры воспроизводимы кодом из репозитория)

| Проверка | Данные | Результат |
|---|---|---|
| 4 семейства стратегий (пробой Дончиана с объёмом, откат к EMA, RSI-возврат, импульс объёма) × 15м/1ч/4ч | 12 монет Bybit, 555 тыс. свечей, подбор на первых 60% времени, тест на последних 40% | **0 из 12 прошли проверку**, на 15м/1ч все убыточны |
| Портфельный поиск (76 конфигураций, позиции {-1,0,1}, издержки, vol-target) | 12 монет, 1ч и 4ч | Выжила одна: **медленный тренд EMA20/100 на 4ч** |
| Независимая проверка выжившей на старых данных | 6 крупных монет, 2020–2023, учтено финансирование | Sharpe **1.15** на непросмотренном окне, **0.93** за 6.5 лет, ~15% в год, макс. просадка ~15%, плюс в каждый из 7 лет |
| Модель TJR (Asia-sweep → BOS → retest OB), 5м | 8 монет, 365 дней | Без комиссий **−0.10R**, с реальными издержками **−0.46R**; зеркальная сделка не хуже |
| «Дискреционный» тест: 10 независимых ИИ-судей отбирают сетапы TJR вслепую | 316 сетапов, без названий и дат | Отбор −0.064R против −0.100R у всех сетапов, p = 0.38 (разницы нет) |
| TJR на индексах, форексе и золоте (5м) | S&P (301 д.), Nasdaq (149 д.), ES/NQ, золото, 60 дней | n = 136, −0.10R, PF 0.80, |t| < 1.3 — преимущества не видно (выборка мала; форекс почти не дал сделок) |

Честные оговорки: выборки на индексах малы, судьи-модели читают графики хуже человека, бэктест не предсказывает будущее, финансирование и комиссии зависят от биржи.

## Что внутри

| Файл | Назначение |
|---|---|
| `data_lake.py`, `funding.py`, `dukas.py` | база свечей Bybit (SQLite), ставки финансирования, минутки Dukascopy (индексы, форекс, золото) |
| `strategy_lab.py` | сделки-уровня: 4 семейства × 3 таймфрейма, walk-forward 60/40, издержки |
| `strategy_lab2.py`, `validate_trend.py` | портфельные позиции, vol-target, проверка на старых данных с финансированием |
| `tjr_lab.py`, `tjr_multi.py`, `tjr_markets.py` | модель TJR с зеркальным контролем на крипте / индексах / форексе |
| `blind_build.py` | слепые пакеты для дискреционной проверки (без исходов, названий и дат) |
| `trend_bot.py` | бумажный тренд-портфель (единственная выжившая стратегия), уведомления в Telegram |
| `memecoin_scanner.py`, `solana_trader.py`, `wallets/` | сканер мемкоинов Solana (DexScreener, RugCheck), **бумажный** трейдер, pre-trade проверка через Jupiter |
| `site_server.py`, `site/index.html`, `exchange_api.py` | локальный дашборд: сигналы, графики со стопами/тейками, риск-калькулятор, статистика |
| `data/*.json` | готовые отчёты исследований |

## Запуск

```bash
python data_lake.py                # скачать свечи (~15–20 минут)
python funding.py                  # ставки финансирования
python strategy_lab.py             # сделки-уровневая лаборатория
python strategy_lab2.py            # портфельная лаборатория
python validate_trend.py           # проверка на старых данных
python tjr_lab.py                  # TJR на крипте (нужны 5м свечи: data_lake.update(sym, '5', 105000))
python site_server.py              # дашборд http://localhost:8080
```

Скопируйте `.env.example` в `.env` только если нужны Telegram-уведомления. Ключи биржи и кошелька в репозиторий не попадают.

## Безопасность
- Торговля **только бумажная** по умолчанию. Реальные ордера Solana включаются только явной переменной `SOL_LIVE=true`; для Bybit в публичную часть торговый код не включён.
- Приватные ключи, `.env`, базы данных, логи и `wallets/hot_wallet.json` в `.gitignore`.
- Мем-коины — крайне рискованный класс; DEX не даёт стоп-ордеров, стопы эмулируются опросом цены.
